# Personas

## The multi-agent builder

Runs Claude Code, Codex, Goose, or Herdr across several repositories and needs
one quiet bar signal that becomes unmistakable when a session blocks.

## The keyboard-first Omarchy user

Moves through panels without a pointer and expects arrows, Enter, Delete, Escape,
Tab, refresh, focus, dismiss, and clear actions to have stable behavior.

## The privacy-conscious maintainer

Needs lifecycle metadata to remain local, bounded, inspectable, and explicit
about the fact that reporter-supplied messages persist on disk.
