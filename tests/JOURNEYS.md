# Acceptance journeys

## Attention handoff

Start one working report and one blocked report through production reporters.
The bar says that one session needs the user. Open the panel, see the blocked
project first with its short headline, activate it, then dismiss it.

## Fleet cleanup

Report working, blocked, and completed sessions from multiple named harnesses.
Navigate rows by keyboard, delete one selected row, clear finished rows, and
verify the working session remains.

## Hostile spool

Attempt a traversal identifier, planted final and temporary links, parent swap,
FIFO, oversized record, directory flood, and concurrent publication. Every
operation finishes within its bound; external targets remain unchanged; the
reader returns only complete same-owner regular JSON records and discloses a
partial fleet.
